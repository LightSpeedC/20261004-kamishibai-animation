# 紙芝居アニメーション

外部サービスを使わず、絵・動き・音声のついた紙芝居を作る試作

> 📅 作成: 2026-10-04 / 更新: 2026-10-05

[⌂](../)

Claude Code と手元のツールだけで、紙芝居アニメーションを作れるかを確かめるプロジェクト。絵は SVG、ナレーションは Windows 標準の音声合成で作り、最後に動画（mp4）にまとめる。クラウドの画像生成・音声合成は使わない。
