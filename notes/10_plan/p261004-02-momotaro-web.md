## 1. 目的

「桃太郎」の冒頭（桃から生まれて名付けられるまで）を、ブラウザで動く紙芝居「桃太郎（冒頭）」にする。絵・字幕・効果音・読み上げ音声をそろえる。

音はすべてブラウザの中で作る。効果音と BGM は Web Audio API、読み上げは Web Speech API を使う。音声ファイル・画像ファイル・外部サービスは使わない。

> [!NOTE]
> **計画 p261004-01 との関係**: p261004-01 の段階 1・2 を、この計画で置き換える。p261004-01 で範囲外にしていた BGM・効果音を含め、読み上げは wav ではなくブラウザで行う。承認後、p261004-01 にこの計画へのリンクと変更点を書く。動画化（段階 3）は p261004-01 のまま残す。

## 2. 台本

昔話のため著作権の制約はない。文は自分で書く。5 場面。

| 場面 | 絵 | ナレーション | 音 |
|---:|---|---|---|
| 1 | 山あいの家と、おじいさん・おばあさん | むかしむかし、ある所に、おじいさんとおばあさんが住んでいました。 | 拍子木（始まり）・BGM 開始 |
| 2 | 山へ向かうおじいさん、川へ向かうおばあさん | おじいさんは山へしばかりに、おばあさんは川へせんたくに行きました。 | 鳥の声 |
| 3 | 川で洗濯するおばあさん。上流から大きな桃が揺れながら流れてくる | おばあさんが川でせんたくをしていると、川上から大きな桃が、どんぶらこ、どんぶらこと流れてきました。 | 川の水音・どんぶらこの揺れに合わせた音 |
| 4 | 家で桃を切ろうとすると、桃が割れて赤ちゃんが出てくる | おばあさんは桃を家に持ち帰りました。おじいさんが包丁で切ろうとすると、桃がぱかっと割れて、中から元気な男の赤ちゃんが生まれました。 | ぱかっ（割れる音）・きらきら |
| 5 | 赤ちゃんを抱く二人 | 桃から生まれたので、二人はこの子を「桃太郎」と名づけました。 | 拍子木（終わり）・BGM 終了 |

台本は HTML の中に JavaScript の配列として持つ。`script.json` に分けると、ファイルを直接開いたとき（`file://`）に読み込めないため。

## 3. 画面と操作

### 画面

- 紙芝居の枠（木の舞台風）の中に、場面の絵を SVG で描く。横長 16:9
- 絵の下に字幕。読み上げ中の文を表示する
- 場面の切り替えは、紙を横へ引き抜く動き（紙芝居の「抜き」）にする
- 場面内の動き: 桃が上下に揺れながら流れる（場面 3）、桃が左右に割れる（場面 4）など、CSS アニメーションで付ける

### 操作

- 最初に「はじまり」ボタンを押す。ブラウザは操作なしに音を出せないため、これが必須
- 自動送り: 読み上げが終わったら、少し間を置いて次の場面へ
- 手動送り: クリック・矢印キーで前後に移る。移ったら読み上げを止めて、その場面を読み直す
- 音・読み上げのオン/オフを切り替えるボタン（字幕だけで読めるように）

## 4. 音と読み上げ

### 効果音と BGM（Web Audio API）

- サンプル `notes/samples/sound-webaudio.html` の作り方（波形をその場で計算）を使う
- 拍子木: 短く高い音を 2 回。鳥の声: 高さを素早く上下させる音。水音: ノイズをフィルターに通して揺らす。ぱかっ: 短いノイズ。きらきら: 高い音の連続
- BGM: 和風に聞こえるよう、ペンタトニック（ド・レ・ミ・ソ・ラ）の短い旋律を繰り返す。読み上げ中は音量を下げる

### 読み上げ（Web Speech API）

- サンプル `notes/samples/speech-webspeech.html` の作り方を使う
- 日本語で、PC の中で動く声（`localService` が true）を優先して選ぶ。無ければネットの声を使い、それも無ければ字幕だけで進める
- 読み上げの終わり（`onend`）で次の場面へ送る
- 読んでいる文字に色を付ける（`onboundary`）。この PC のブラウザで位置が届くかは未確認。届かなければ文単位の表示にする

> [!NOTE]
> **読みの誤り**: 音声合成は「川上」「包丁」などを読み違えることがある。その場合は、読み上げる文だけをひらがなにする（字幕は漢字のまま）。台本には字幕用と読み用の 2 つの欄を持たせる。

## 6. 決めること

実装前に決めてほしい点。推奨は A。

- **1. 範囲**
    - 1-A: 名づけまで（5 場面）。冒頭として切りがよい
    - 1-B: 鬼退治に出発するまで（7〜8 場面）
- **2. 読み上げ**
    - 2-A: Web Speech API。ブラウザだけで完結し、台本を直せばすぐ反映される。声はブラウザ・PC によって変わる
    - 2-B: Windows の音声合成で wav を作り、HTML で再生する。声は固定できるが、台本を直すたびに作り直しが要る
- **3. 絵の調子**
    - 3-A: 太い輪郭と平塗りの、紙芝居らしい単純な絵
    - 3-B: 影・グラデーションを付けた絵本風。手間が倍ほどかかる
