サンプル: Web Audio API の効果音と BGM

📅 作成: 2026-10-04 / 更新: 2026-10-04
⌂

ブラウザの Web Audio API で、波形をその場で計算して鳴らす。音声ファイルは使わない。ブラウザは操作なしに音を出せないため、ボタンを押して鳴らす。

効果音

  • ピュン: 矩形波の高さを 1400 Hz から 200 Hz へ下げる
  • ピロリン: ド・ミ・ソ（高い音域）を少しずつずらして鳴らす
  • ドカーン: ノイズを、高い音を削るフィルターに通し、だんだん小さくする

BGM

  • 曲は「かえるの合唱」（ドイツ民謡）。メロディは矩形波、低音は三角波で、終わると頭から繰り返す
  • 音の高さは、ラ（440 Hz）から半音 n 個離れた音を 440 × 2^(n/12) で出す
