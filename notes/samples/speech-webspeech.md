# サンプル: Web Speech API の読み上げ

> 📅 作成: 2026-10-04 / 更新: 2026-10-05

[⌂](../../README.md)

ブラウザ標準の Web Speech API（`speechSynthesis`）で読み上げる。文章・声・速さ・高さ・音量を変えて試せる。

## 読み上げ

文章 むかしむかし、ある山のふもとに、小さな村がありました。 声 内蔵の声だけを出す 日本語の声だけを出す 速さ

1.0

高さ

1.0

音量

1.0

読み上げ 停止

## このブラウザで使える声

「内蔵」は `localService` が `true` の声で、PC・スマホの中で動き、ネットに繋がずに読める。「ネット」はブラウザの提供元のサービスへ文章を送って読み上げる。
